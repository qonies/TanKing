# 需求文档（PRD）

**项目**：TanKing —— FC《坦克大战》网页复刻版
**版本**：v0.3（已评审确认；含 2026-10-19 二次修订）
**日期**：2026-10-19
**状态**：决策点已全部确认；M1 单机核心已完成，M2 联机待启动

---

## 1. 项目概述

在浏览器中复刻 FC 经典游戏《坦克大战》（Battle City, Namco, 1985）的核心机制，并将原版"同屏双人"升级为**局域网多人 PvP 死亡竞技**。完整保留原版元素：五种地形、道具系统、可破坏基地；支持 AI 机器人坦克填充空位。

### 1.1 核心定位
- **核心玩法：PvP 死亡竞技**（已确认）—— 玩家互相攻击，总积分决定胜负（1 击杀 = 100 分）；合作闯关模式不在本期范围。
- **内容范围：完整原版元素**（已确认）—— 地形、道具、基地、AI 全部保留，效果做 PvP 适配。

### 1.2 目标用户与场景
| 场景 | 描述 |
|---|---|
| 局域网聚会 | 办公室/宿舍/家庭网络内 2~8 名参战者（真人 + AI，默认 6）联机对战 |
| 单机休闲 | 离线与 AI 机器人对战、练习操作 |

## 2. 功能需求

### 2.1 坦克系统（FR-T）

| 编号 | 需求 | 说明 |
|---|---|---|
| FR-T1 | 格子化移动 | 四方向移动，对齐半格（原版手感）；松开按键自动对齐网格 |
| FR-T2 | 射击 | 同屏子弹数量受坦克等级限制；子弹可被对方子弹抵消（原版机制） |
| FR-T3 | 坦克等级 0~3 | ★升级：L0 基础 → L1 快速子弹 → L2 双发子弹 → L3 可破坏钢墙；被击毁降 1 级（已确认） |
| FR-T4 | 属性差异 | 等级影响移动速度、子弹速度、同屏弹量、破坏力（需按原版参数表核对） |
| FR-T5 | 护盾 | 重生后 3 秒无敌（视觉为闪烁护罩），护盾期内不可被击毁 |
| FR-T6 | 生命/重生 | PvP 模式下无限重生；被击毁 2 秒后在出生点/随机安全点重生 |

### 2.2 地形系统（FR-M）

网格：原版 13×13 大格（每大格 2×2 小格，共 26×26 小格单元）。

| 编号 | 地形 | 行为 |
|---|---|---|
| FR-M1 | 砖墙 | 可破坏，按 1/4 大格（小格单元）粒度损毁；L3 坦克子弹可整格摧毁 |
| FR-M2 | 钢墙 | 不可破坏；L3 坦克子弹可摧毁 |
| FR-M3 | 水面 | 阻挡坦克，子弹可穿越 |
| FR-M4 | 树林 | 不阻挡坦克与子弹，遮挡坦克视觉（渲染在最上层） |
| FR-M5 | 冰面 | 不阻挡；坦克在冰面上有滑行惯性（原版手感） |
| FR-M6 | 基地（老鹰） | 全局唯一中立基地，位置固定，可被任意玩家子弹摧毁；摧毁者 +500 分，回合不结束（已确认） |

### 2.3 道具系统（FR-P）

地图上周期性刷新（原版为击毁特定闪红坦克掉落，PvP 适配为地图定点刷新 + 低概率闪红 AI 掉落）。

| 编号 | 道具 | 原版效果 | PvP 适配 |
|---|---|---|---|
| FR-P1 | 星星 ★ | 坦克升 1 级 | 不变（L3 满级时改为 +100 分） |
| FR-P2 | 头盔 | 10 秒护盾 | 不变 |
| FR-P3 | 定时器 | 冻结所有敌人 | 冻结所有对手 8 秒（拾取者可正常行动） |
| FR-P4 | 炸弹 | 消灭所有敌人 | 消灭全图所有对手 |
| FR-P5 | 铁锹 | 基地周围变钢墙 15 秒 | 中立基地周围变钢墙 15 秒（到期恢复原状） |
| FR-P6 | 坦克 | +1 生命 | PvP 无生命概念，改为 +200 分 |

### 2.4 AI 机器人（FR-A）

| 编号 | 需求 |
|---|---|
| FR-A1 | 机器人填充空位，房主可配置数量与难度 |
| FR-A2 | 行为模型：随机巡逻 + 嗅探玩家/道具/基地方向、遇障碍变向、卡墙检测、遇敌射击，行为与原版敌人 AI 风格一致 |
| FR-A3 | 三档难度：简单（低射速/低命中率）、普通、困难（会抢道具、会护家） |

### 2.5 联网与房间（FR-N）

> 术语约定：**主机（Host）** ＝ 运行服务器进程的机器；**房主（RoomOwner）** ＝ 房间内拥有设置/开始权限的玩家（默认为房间创建者）。

| 编号 | 需求 |
|---|---|
| FR-N1 | 一台机器启动主机（Node 服务），同网段设备浏览器访问 `http://<主机IP>:<端口>` 加入 |
| FR-N2 | 大厅：昵称输入、房间列表/房间创建、房间内成员列表、准备/开始（房主权限） |
| FR-N3 | 房主可设置：地图选择、AI 数量与难度、回合规则（积分上限/时长）、道具开关（真人 + AI 合计不超过总坦克上限 8） |
| FR-N4 | 游戏中断线：该玩家坦克由 AI 托管，60 秒内重连可接管原位（尽力而为，不可行则判离场） |
| FR-N5 | 通信：WebSocket；上行输入包，下行状态快照，服务器权威 |
| FR-N6 | （本期不实现，二期候选）UDP 广播自动发现主机，玩家无需手输 IP |

### 2.6 界面（FR-U）

| 编号 | 界面 | 内容 |
|---|---|---|
| FR-U1 | 主菜单 | 开始游戏 / 单机模式 / 设置（音量、键位） |
| FR-U2 | 大厅/房间 | 昵称、成员列表、地图预览、设置面板、文字聊天区、开始按钮 |
| FR-U3 | 对局 HUD | 两侧信息栏：玩家积分（含击杀数）、等级、存活状态、回合剩余时间；Tab 显示完整计分板 |
| FR-U4 | 结算画面 | 排名、击杀/死亡统计、MVP、"再来一局"（回房间） |
| FR-U5 | 击杀播报 | 顶部滚动：A 击毁了 B / B 摧毁了 A 的基地 |

### 2.7 操作与设置（FR-S）

| 编号 | 需求 |

## 3. 非功能需求

| 编号 | 类别 | 需求 |
|---|---|---|
| NFR-1 | 性能 | 渲染 60fps；服务器逻辑 tick 固定 60Hz；单房间 8 坦克（真人 + AI 合计）满载时 CPU 占用无明显抖动 |
| NFR-2 | 延迟 | 局域网（RTT < 10ms）内操作到画面反馈感知延迟 < 50ms |
| NFR-3 | 兼容性 | Chrome/Edge/Firefox 最新两个大版本；1920×1080 与 1366×768 下布局正常 |
| NFR-4 | 易部署 | 主机一条命令启动（`npm start` 或打包单文件）；客户端零安装 |
| NFR-5 | 可靠性 | 单个玩家断线不影响对局；服务器崩溃时可重启恢复大厅（对局不要求恢复） |
| NFR-6 | 安全 | 仅监听局域网接口；房间人数/昵称校验；输入包频率限制（防刷） |
| NFR-7 | 版权 | 全部美术/音效自制或 CC0，风格致敬原版；代码与素材不含原版 ROM 资源 |

## 5. 已确认决策点（2026-10-19 评审通过；D1~D3 同日二次修订）

> v0.3 修订（2026-10-19）：D1 改为积分制（方案 A）；D2 基地明确为全局唯一中立基地；D3 上限明确为真人 + AI 合计 8 个坦克。

| # | 决策点 | 确认结果 |
|---|---|---|
| D1 | 回合胜负 | 积分制：1 击杀 = 100 分；默认积分上限 1000 分、时长 8 分钟（均可配置）。先达积分上限者胜；时长耗尽则积分最高者胜 |
| D2 | 基地被摧毁 | 全局唯一中立基地，摧毁者 +500 分，不结束回合 |
| D3 | 人数上限 | 总坦克数（真人 + AI 合计）默认 6（4 真人 + 2 AI 起步），上限 8，均可配置 |
| D4 | 文字聊天 | 房间内文字聊天，游戏中仅快捷短语（避免打字影响操作） |
| D5 | tick 频率 | 60Hz 逻辑 + 快照按 tick 广播，客户端 2 帧缓冲插值 |
| D6 | 被击毁降级 | 降 1 级（鼓励道具争夺） |
