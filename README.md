# TanKing · 坦克大战网页复刻版

基于浏览器的 FC 经典《坦克大战》（Battle City, 1985, Namco）复刻项目，核心玩法为**局域网多人 PvP 死亡竞技**：完整保留原版地形、道具与基地元素，支持 AI 机器人填充空位，离线单机亦可直接游玩。

> **版权声明**：本项目仅复刻玩法机制与像素风格，不包含、不提取任何原版 ROM 素材（贴图 / 音效 / 音乐）。原版素材版权归 Namco 所有，本项目全部美术与音效均为自制或 CC0 素材。

## 当前状态

- **M1 单机核心**：已完成 —— 60Hz 固定步长模拟、半格吸附移动、五种地形、砖墙破坏、子弹互消、击杀计分、护盾 / 重生、积分制胜负、BFS 寻路 AI（29 个单元测试全绿）
- **M2 联机打通**：待启动（下一里程碑）—— WebSocket 服务器、房间流程、快照同步

## 已实现玩法（M1）

- **格子化移动**：方向键 / WASD 移动，松开或转向时自动吸附半格网格，还原原版手感
- **五种地形**：砖墙（按 1/4 大格粒度破坏）、钢墙、水面（阻挡坦克、子弹可穿越）、树林（遮挡视觉）、冰面（滑行惯性）
- **战斗机制**：同屏弹量限制、子弹互消、护盾期免疫、击毁 2 秒后带 3 秒护盾重生
- **积分制胜负**：1 击杀 = 100 分，先达默认 1000 分者胜
- **AI 机器人**：BFS 寻路 + 对齐瞄准 + 卡墙检测开火开路

## 技术栈

| 层 | 选型 | 说明 |
|---|---|---|
| 语言 | TypeScript | 前后端共享纯逻辑（`shared/`） |
| 构建 | Vite | 开发热更新，产物即静态文件 |
| 渲染 | Canvas 2D | 416×416 逻辑分辨率，禁用平滑的像素风渲染 |
| 测试 | Vitest | headless 单元测试，种子化 PRNG 保证可复现 |

## 快速开始

要求 Node.js ≥ 20。

```bash
npm install     # 安装依赖
npm run dev     # 启动开发服务器，浏览器打开即玩（离线单机模式）
npm test        # 运行单元测试
npm run build   # 类型检查 + 生产构建
```

## 操作说明

| 按键 | 功能 |
|---|---|
| 方向键 / WASD | 移动 |
| 空格 / J | 射击 |
| R | 重新开始 |

## 目录结构

```
TanKing/
├─ shared/        # 前后端共享纯逻辑：模拟器、AI、地图加载、常量表
├─ client/        # Canvas 渲染、键盘输入、固定步长主循环
├─ maps/          # JSON 关卡文件
├─ tests/         # Vitest 单元测试
├─ docs/          # 需求文档、技术路线、测试文档、参数对照表
└─ memory-bank/   # 项目知识库
```
