# TanKing · 坦克大战网页复刻版

基于浏览器的 FC 经典《坦克大战》（Battle City, 1985, Namco）复刻项目，核心玩法为**局域网多人 PvP 死亡竞技**：完整保留原版地形、道具与基地元素，支持 AI 机器人填充空位，离线单机亦可直接游玩。

> **版权声明**：本项目仅复刻玩法机制与像素风格，不包含、不提取任何原版 ROM 素材（贴图 / 音效 / 音乐）。原版素材版权归 Namco 所有，本项目全部美术与音效均为自制或 CC0 素材。

## 已实现玩法（M1~M4）

- **格子化移动**：方向键 / WASD 移动，松开或转向时自动吸附半格网格，还原原版手感
- **五种地形**：砖墙（按 1/4 大格粒度破坏）、钢墙、水面（阻挡坦克、子弹可穿越）、树林（遮挡视觉）、冰面（滑行惯性）
- **战斗机制**：同屏弹量限制、子弹互消、护盾期免疫、击毁 2 秒后带 3 秒护盾重生
- **四级坦克**（M3）：★升级 —— L1 快速子弹、L2 双发、L3 破钢 + 砖墙整格摧毁；被击毁降 1 级
- **六种道具**（M3）：星星（升级 / 满级 +100）、头盔（10s 护盾）、定时器（冻结对手 8s）、炸弹（全图对手击毁计分）、铁锹（基地钢墙 15s）、坦克（+200）
- **中立基地**（M3）：全局唯一、摧毁 +500 分、回合不结束
- **积分制胜负**：1 击杀 = 100 分，先达默认 1000 分者胜；8 分钟限时积分最高者胜
- **AI 机器人**：BFS 寻路 + 对齐瞄准 + 卡墙检测开火开路
- **音效**（M3）：Web Audio 合成 8-bit 音效（射击 / 爆炸 / 拾取 / 升级 / 基地摧毁）

## 技术栈

| 层 | 选型 | 说明 |
|---|---|---|
| 语言 | TypeScript | 前后端共享纯逻辑（`shared/`） |
| 构建 | Vite | 开发热更新，产物即静态文件 |
| 渲染 | Canvas 2D | 416×416 逻辑分辨率，禁用平滑的像素风渲染 |
| 服务端 | Node.js ≥ 20 + `ws` | HTTP 静态托管 + WebSocket 同端口，服务器权威 |
| 测试 | Vitest | headless 单元 / 集成测试，种子化 PRNG 保证可复现 |

## 快速开始

要求 Node.js ≥ 20。

```bash
npm install          # 安装依赖
npm run dev          # 开发模式：Vite(5173，监听 0.0.0.0 供局域网访问) + 游戏服务器(3000) 并行，浏览器打开 http://localhost:5173
npm test             # 运行单元 / 集成测试
npm run build        # 类型检查 + 生产构建
# 局域网联机（其他设备访问）务必使用生产模式：npm run build && npm start（start 前会检查 dist 产物）
npm start            # 生产模式：单端口 3000 托管（需先 build），局域网其他设备访问 http://<主机IP>:3000
```

## 联机说明（M2~M4）

1. 房主运行 `npm run build && npm start`（或开发模式 `npm run dev`），放行 3000 端口
2. 其他设备浏览器访问 `http://<主机IP>:3000`，输入昵称点「联机对战」
3. 房主在房间内配置坦克总数（2~8，默认 6）与 AI 难度（简单 / 普通 / 困难），点击「开始游戏」→ 3 秒倒计时 → 对局；人数不足由 AI 补位
4. 对局中断线的玩家坦克由 AI 托管，60 秒内以相同昵称重连可接管原坦克

## 操作说明

| 按键 | 功能 |
|---|---|
| 方向键 / WASD | 移动（主菜单「键位设置」可自定义，自动保存） |
| 空格 / J | 射击 |
| 1~5（对局中） | 发送快捷短语 |
| R | 重新开始（单机） |

## 目录结构

```
TanKing/
├─ shared/        # 前后端共享纯逻辑：模拟器、AI、地图加载、常量表、协议类型
├─ server/        # 游戏服务器：房间状态机、tick 循环、HTTP+WS 入口
├─ client/        # Canvas 渲染、键盘输入、快照插值、连接管理、固定步长主循环
├─ maps/          # JSON 关卡文件
├─ tests/         # Vitest 单元 / 集成测试
├─ docs/          # 需求文档、技术路线、测试文档、参数对照表
└─ memory-bank/   # 项目知识库
```
